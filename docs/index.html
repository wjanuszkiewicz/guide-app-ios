GuideApp iOS

Краткая документация по настройке и запуску проекта.

Требования

  • Xcode 15+, iOS 15+
  • Firebase (Auth), MapLibre

Быстрый старт

  1. Подключите пакеты Firebase и MapLibre через Swift Package Manager
  2. Добавьте GoogleService-Info.plist в проект
  3. Вставьте свой ключ MapTiler в Views/Map/MapView.swift в параметр key=
  4. Запустите проект на симуляторе или устройстве

Авторизация

Доступны Email/Пароль, Телефон, Apple и анонимный вход. После успешной авторизации флаг hasSeenAuth снимает онбординг.
